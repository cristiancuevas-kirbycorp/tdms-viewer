TDMS Viewer BETA

Open, defragment, graph, and analyze National Instruments TDMS files on Windows — multi-axis plots, calculated channels, and draggable cursors. No LabVIEW or DIAdem required.

⬇  Download the Beta (Windows)
Windows 10/11 · 64-bit · single file, no install · all releases

Data Portal

Browse groups and channels with units, a live properties table, and a preview graph. Smart multi-word search with highlighting.

Multi-axis plotting

Named Y-scales you assign plots to, with left/right side and auto or fixed min/max. Reports and pages, savable as a project.

Cursors & stats

Two draggable time cursors with a shaded band and a readout of each plot's value at A/B, the delta, and min/max/avg between them.

Calculated channels

Build new channels from math expressions across existing channels, then plot them like any other signal.

  1. Download the button above — it's a single self-contained .exe, no .NET install needed.
  2. Run it. Windows SmartScreen may warn on first launch (unsigned app) — click More info → Run anyway.
  3. Open a TDMS file via File → Open TDMS and start plotting.
